# Site do WTISC 2018

Site do Workshop de Tecnologia da Informação do Sertão Central (WTISC) 2018, evento da Universidade Federal do Ceará (UFC) — Campus Quixadá, realizado pelo grupo PET - Sistemas de Informação.

### O que o site contém

- **O Evento** — apresentação do evento
- **Programação** — minicursos, palestras, mesa redonda e hackathon
- **Inscrições** — informações sobre as inscrições
- **Contato** — realização e contatos

## Stack

- [Bulma](https://bulma.io/) — framework CSS
- HTML e JavaScript puros

## Como rodar

O site é estático. Basta abrir o `index.html` no navegador ou servir a pasta com um servidor simples:

```sh
python -m http.server 8000
```

Acesse `http://localhost:8000/`.
